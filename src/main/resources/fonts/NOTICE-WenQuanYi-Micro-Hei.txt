HomeBox bundles this font so that Apache PDFBox can render CJK text of PDF
invoices that reference fonts which are not embedded in the PDF file (for
example KaiTi / SimSun / SimHei in Chinese railway e-invoices). Without a
bundled fallback the preview is rendered with PDFBox's Latin-only last-resort
font on hosts that have no CJK fonts installed (e.g. the Alpine based Docker
image), which silently drops all Chinese characters from the preview image.
